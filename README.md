# Geophysical data repository (ERT and RST) of the Tien Shan and Pamir (Kyrgyzstan and Tajikistan) 2021 - 2025
Electrical Resistivity Tomography (ERT) and Refraction Seismic Tomography (RST) datasets monitoring mountain permafrost across the Tien Shan and Pamir ranges of Central Asia.
